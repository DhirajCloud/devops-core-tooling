# Code of Conduct

## Our Commitment
We aim to maintain a welcoming, respectful, inclusive, and harassment-free project community.

## Expected Behavior
- Be respectful and constructive.
- Welcome different perspectives.
- Give feedback professionally.
- Respect contributors and their time.

## Unacceptable Behavior
Harassment, discrimination, intimidation, personal attacks, and abusive language are not acceptable.

## Reporting
Report unacceptable behavior privately to the project maintainers through the repository's available contact channels.

## Reference
This project follows Contributor Covenant version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
