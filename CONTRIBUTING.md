# Contributing Guidelines

## Getting Started
1. Clone the repository.
2. Create a feature branch from main.
3. Set up a Python virtual environment.
4. Install dependencies using pip install -r requirements.txt.

## Branch Naming
- feature/description
- fix/description
- docs/description
- test/description

## Development Standards
- Write clean, maintainable Python code.
- Follow Python coding conventions.
- Add tests when functionality changes.
- Never commit passwords or secrets.
- Update documentation when required.

## Quality Checks
Run Flake8 and Pytest before submitting changes.

## Pull Requests
1. Push your feature branch.
2. Open a pull request targeting main.
3. Describe your changes.
4. Include test results.
5. Address review feedback.
6. Ensure CI checks pass.

## Commit Messages
Use descriptive messages, such as:
- feat: add dashboard functionality
- fix: correct validation
- docs: update README
